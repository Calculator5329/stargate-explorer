Will this fit the existing Three.js app?

The file loads today. Blender exported a self-contained GLB; this viewer calls the app’s existing GLTFLoader helper. Four named attachment nodes have the expected +Z-forward, +Y-up positions. The toon preview uses the game’s material helpers and outline code.

It is not a drop-in playable ship yet. ShipRig still builds procedural definitions. Integration would need an asynchronous asset/preload path, attachment-driven plumes and muzzle effects, and checks for scale, collision, faction recoloring, disposal and replay. None of that has been substituted into the fleet.

The metallic mode uses exported PBR materials and a neutral generated reflection environment. The toon mode uses the current glider’s palette. All comparisons share studio lights, an orthographic camera and union bounds. No engine plumes, normal maps or gameplay effects are included.
