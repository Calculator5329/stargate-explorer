# Stargate Explorer

Browser space-combat game: Three.js + TypeScript + Vite, no engine, all art procedural.

```
npm install
npm run dev      # http://localhost:5187
npm run build
```

Planning lives in `docs/`: `roadmap.md` (what's next), `STATUS.md` (what works), `DECISIONS.md` (why), `GRAPHICS.md` (the look). Agents read `CLAUDE.md` first.
